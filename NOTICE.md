# 저작권과 출처

Tushonka Cleaner 3.0.0 통합·유지보수: R_F.
통합 배포물에는 GPL-3.0이 적용되며 전문은 `LICENSE`에 있습니다.
기존 저작자의 저작권과 각 원본에 적용되는 라이선스는 유지합니다.
아래 링크는 통합 입력 자료의 README 머리말에서 옮겼습니다.

1. **CactusPie — SPT-RamCleanerInterval**
   - 원본: https://github.com/CactusPie/SPT-RamCleanerInterval
   - 라이선스: GPL-3.0 (`LICENSE`). 메모리 정리·보고·진단 기능의 기반입니다.
2. **matsix — SPTVRAMCleaner**
   - 원본: https://github.com/matsixx/SPTVRAMCleaner
   - 라이선스: GPL-3.0 (`LICENSE`). 레이드 시작 시 에셋 정리 기능의 기반입니다.
3. **EchoStarz — CompoundingPerf**
   - 원본: https://forge.sp-tarkov.com/mod/2415/compoundingperf
   - 라이선스: MIT. 서버 최적화·설정·진단과 클라이언트 C1·C2 기능의 기반입니다.
